sound-recreation-agent

The orchestrating AI agent — it listens to a song, identifies the sound engine, predicts synth parameters, and sets them on your keyboard over MIDI.

★ View on GitHub Read the docs
What it does

The brain of the pipeline

Built on the Vercel AI SDK ToolLoopAgent and MCP, it drives keyboards-mcp and audio-analysis-mcp over stdio: fetch audio, separate stems, isolate the keyboard part, identify the engine, predict parameters, and apply them. The HTTP server is stateless — conversation history lives in the client.

Orchestrates two MCP servers
keyboards-mcp (Node) + audio-analysis-mcp (Python) over stdio
Agentic loop
Vercel AI SDK ToolLoopAgent → AI Gateway → LLM
Streaming HTTP API
Stateless server; POST /chat with SSE streaming
REPL + CLI flags
--keyboards-mcp, --audio-mcp, --port
Env-based secrets
AI_GATEWAY_API_KEY (+ optional TAVILY_API_KEY)
Zero-dep tests
node:test unit + integration suites
Quickstart

Up and running

# install
npm install

# provide secrets (1Password helper, or export env yourself)
cp scripts/dev.local.sh.example scripts/dev.local.sh

# start the agent + both MCP servers
npm run dev:full

# in another terminal: connect the REPL
npm run repl
In the pipeline

Where it fits

Audio→Analysis→Agent→MIDI→Synth

sound-recreation-agent is the orchestrator — the loop that turns analysis into MIDI.
